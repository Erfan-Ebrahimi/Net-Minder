# Net-Minder

Persian RTL marketing website for hotel reservation management products, built with HTML, CSS and JavaScript.

<p dir="rtl">وب‌سایت فارسی معرفی محصولات مدیریت رزرو آنلاین هتل.</p>

[Deployment link](https://net-minder.vercel.app) · [Source](https://github.com/Erfan-Ebrahimi/Net-Minder)

## Stack

HTML · CSS · JavaScript

## What's inside

- Persian product, benefits and workflow sections
- Hotel reservation product presentation
- Separate page, style and script directories

## Local setup

Serve the repository root with a local static web server, then open `index.html`. No npm build step is configured in this repository. Keep the asset folders next to the HTML files.

## Project layout

- `index.html` — main landing page
- `Pages/` — additional pages
- `styles/` — stylesheets
- `scripts/` — browser interactions
- `images/` — visual assets

## Project notes

This repository contains the website interface. It does not include a hotel reservation backend.
